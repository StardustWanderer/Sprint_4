# Автоматизация тестирования сервиса «Яндекс Самокат»

Проект содержит UI-автотесты для веб-приложения «Яндекс Самокат». Тесты покрывают ключевые бизнес-сценарии: пошаговое оформление заказа через разные точки входа и валидацию текстового содержимого в блоке FAQ (аккордеон).

## 🛠 Технологический стек

* **Язык программирования:** Java (v11)
* **Тестовый фреймворк:** JUnit 4 (v4.13.2)
* **Инструмент автоматизации веб-браузера:** Selenium WebDriver (v4.45.0)
* **Сборщик проектов:** Maven
* **Паттерн проектирования:** Page Object Model (POM)

## 🏗 Архитектура проекта

Тесты организованы с использованием паттерна Page Object для разделения логики тестов и структуры страниц:
* `BasePage` — базовый класс для страниц с общими методами ожидания элементов.
* `MainPageScooter` — главная страница (аккордеон вопросов, кнопки заказа).
* `OrderPageScooter` — первая форма заказа («Для кого самокат»).
* `RentPageScooter` — вторая форма заказа («Про аренду») и модальные окна.
* `BaseTest` — базовый класс для тестов (инициализация драйвера, открытие браузера, закрытие после теста).

### 🧪 Тестовые классы:
* `CreateOrderTest` — параметризованный end-to-end тест создания заказа (проверяет позитивный сценарий оформления через верхнюю и нижнюю кнопки «Заказать»).
* `AccordionFaqTest` — параметризованный тест для проверки раздела «Вопросы о важном» (последовательно раскрывает все 8 панелей аккордеона и валидирует текст ответов).

## ⚠️ Важное примечание (Известный баг в Chrome)
В приложении присутствует дефект на фронтенде, который воспроизводится **только в браузере Google Chrome**: после подтверждения заказа в модальном окне не отображается финальный поп-ап «Заказ оформлен». 

* В связи с этим тест `CreateOrderTest` в Chrome будет падать по таймауту (`TimeoutException`).
* Кроссбраузерность проверена: в браузере **Firefox** тест `CreateOrderTest` проходит со 100% успехом (зелёный). 
* Тест `AccordionFaqTest` успешно проходит в **обоих браузерах**, так как данный дефект его не затрагивает.
